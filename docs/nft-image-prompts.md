## Generation Instructions

### Using Midjourney:
1. Go to Discord Midjourney bot
2. Use `/imagine` command
3. Paste prompt
4. Select best variation
5. Upscale to full resolution
6. Download PNG

### Using DALL-E 3:
1. Go to ChatGPT Plus or Bing Image Creator
2. Paste prompt
3. Generate 4 variations
4. Select best one
5. Download PNG

### Post-Processing:
1. Remove background if not transparent (use remove.bg)
2. Resize to exactly 512x512px
3. Optimize PNG (use TinyPNG)
4. Save as: `achievement_[id].png`
